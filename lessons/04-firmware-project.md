# Lesson 04 — Build a responsive device controller

This phase develops one firmware project through meaningful increments. Start with [the device controller](../projects/device_controller/README.md).

The first increment separates application logic from an output driver, replaces blocking waits with elapsed-time checks, and keeps command handling active during blinking. Read and modify the component interface, implementation, and main loop together.

Later increments introduce operating modes, real inputs, peripheral drivers, interrupts, and hardware-register investigation. Hardware-dependent work uses the components available to the learner. Prior exercises remain reference material; no extra testing curriculum is required before starting this project.
